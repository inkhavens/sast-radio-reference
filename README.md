# SAST Radio Reference

Radio reference and study tool for the San Andreas State Troopers on Project Tropics RP.

- **Phonetic Alphabet**: letters, numbers and a spell it out tool
- **10 Codes**: the full server 10 code handbook with search
- **Study**: flashcards, quiz, 60 second speed round and a plate drill. Progress saves in your browser.

Plain HTML, CSS and JavaScript. No build step.
